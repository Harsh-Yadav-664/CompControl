How to connect Cloud AI or Local Ollama

In the native Windows app, click ⚙ AI Settings, select Groq / Gemini / NVIDIA NIM / Ollama, paste your key, and check Remember AI settings on this PC. Or set environment variables before launching:

$env:COMPCONTROL_PROVIDER = "openai"
$env:COMPCONTROL_BASE_URL = "https://api.groq.com/openai/v1"
$env:COMPCONTROL_MODEL = "openai/gpt-oss-20b"
$env:COMPCONTROL_API_KEY = "your-api-key"
