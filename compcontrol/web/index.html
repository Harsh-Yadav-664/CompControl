How to connect a local model

Install Ollama separately, download a model that fits your hardware, then set these in PowerShell before starting CompControl:

$env:COMPCONTROL_PROVIDER = "ollama"
$env:COMPCONTROL_MODEL = "your-installed-model"
py -3 -m compcontrol

No model is downloaded by CompControl. Only explicitly submitted AI questions are sent. Text responses have no access to tools, command history, files or credentials.

Approval policy

Every desktop effect requires review here and a separate Windows confirmation. Approvals are single-use and expire after two minutes.

ALWAYS ON
